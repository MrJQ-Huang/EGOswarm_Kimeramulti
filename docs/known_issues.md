# 已知问题与验收状态

当前快照能够完成双机协同飞行和部分原生稠密建图，但尚未通过持续局部建图与同轮全局融合验收。不能仅凭 RViz 刷新或单次网格变形成功判断完整系统已经复现。

## 最近一次双机实验

2026 年 11 月 2 日运行两圈闭环任务，实际飞行持续 500.4466 秒。原始传感器、原生 VIO、地图输入、实际积分日志和版本校验分别监测。[本轮摘要](evidence/concurrency_analysis.json)

| 指标 | AMOV | UROS |
| --- | ---: | ---: |
| 实际运动路径 | 160.21 m | 158.46 m |
| 飞行期间原生 TSDF 实际积分 | 47 次 | 84 次 |
| 最后接收的优化请求序号 | 40 | 25 |
| 整机 CPU 中位数 | 93.00% | 59.05% |
| 整机 CPU P95 | 97.80% | 73.33% |

AMOV 飞行末尾约 390 秒没有新增实际积分。两机最后接受的原生网格对应不同请求窗口和不同最终权重；全局同轮校验通过次数为 0，因此没有可称为本轮成功融合的最终全局地图。

按实际飞行窗口截取，AMOV 的 CPU 统计包含 445 个样本，末尾约 55.7 秒因采样脚本异常缺失，不能把缺样解释为 SLAM 崩溃。UROS 包含 500 个样本，基本覆盖全程。整机 CPU 与进程 CPU 口径不同，具体资源定义见[资源分析](evidence/performance_analysis.json)。

## 局部地图输入积压

此前桥接层在 PGMO 事务期间直接暂停局部点云输入，该逻辑已移除。本轮 UROS 一次约 6.27 秒的 PGMO 事务内，原生 TSDF 实际完成 6 次积分，说明两条链路可以同时工作。

持续运行仍存在问题：桥接层图和网格操作、序列化、RGB-D 配对以及 IMU/里程计处理共享调度与锁。大消息可能延后局部输入，队列积压后继续发布的也是旧时间戳数据。

只读探针观察到 AMOV 一对时间戳相同的点云和 TF 均滞后约 56 秒；该观测排除了这对数据的简单 TF 与点云时间戳不一致，但不能解释全部失效。原生 TSDF 有队列过长与丢弃告警，具体变换查询失败、队首阻塞及 TF 缓存过期路径仍需专门复现确认。

## 算力压力与软件瓶颈

AMOV 的 Orin NX 在该轮只有 4 个 CPU 核在线，整机负载接近饱和，存在明确的 CPU 竞争。实验后的只读查询显示 15W 模式，配置限制为四核在线、CPU 上限 1.4208 GHz；未修改功耗模式。UROS 的 i7-7820HQ 有 8 个逻辑 CPU，相关 Docker 未配置 CPU 配额限制；整机未饱和也出现输入与积分停顿。

UROS 的 `native_dense_bridge.py` 进程 CPU 中位数约为单核的 95%，P95 约 99%，形成串行处理瓶颈；AMOV 同一进程约为单核的 51% 与 68%，其压力来自多进程竞争。原生 TSDF 单次积分为几十毫秒量级，积分进程并未满核，不能把消息排队时间都算作 TSDF 算法耗时。共享锁已从代码确认，但各处理步骤的耗时占比仍需逐线程与锁计时分析。

因此，当前不能归因为“UROS 整机算力不够”，也不能承诺升级机器就会消除问题。需要先量化各进程与线程的耗时、锁等待、排队年龄和 TF 查询结果，再调整负载与硬件配置。两机当轮可用内存仍为 GB 量级，没有证据将本次故障归为内存耗尽。

## 全局版本提交未完成

原生 DPGO 消息没有跨节点共享的原子 round ID。桥接层依据请求和终止窗口、最终权重以及轨迹回执观测完成状态，跨 topic 的接收顺序仍会造成候选失效、超时或两机接受不同版本。

全局收集器拒绝混合版本是显示保护规则；导致两机长期不能提交同一轮结果的调度和协议问题仍未修复。它与局部 TSDF 积分停顿相关联，但不是同一个问题。

## 其他边界

- 现有 VIO 仍有累计漂移；IMU 旋转插值改善了局部回投，不等于消除原生估计误差。
- 编译、单元测试、短时回放与单次原生网格变形的通过，不代表长时间双机实验通过。
- 规划仍依赖仿真里程计与障碍观测，未验证 SLAM 对导航的反馈闭环。
- 当前无语义标签推理、真实硬件建图或通信失联容错验收。

## 下一阶段验收

1. 单机持续输入：定义点云与 TF 最大年龄、吞吐和丢弃上限，覆盖完整闭环飞行。
2. 单机并行：在图和网格事务期间持续记录原生 TSDF 积分，检查锁与队列延迟。
3. 双机同轮：以共同轮次提交两份网格，匹配请求窗口、最终权重和原生变形证据。
4. 全局发布：用实际发布的顶点哈希与持久化结果对应，保证没有旧轮次混入。
5. 几何质量：独立评估轨迹、重叠表面和地图误差，真值只用于离线评价。
